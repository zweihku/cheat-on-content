# EP01 美术方向：「星历」

**一句话**：把人间的数字，刻进天上的历书里。观众看到的每一个数，都像是早就写在星空和古籍里，只等被翻到那一页。

样张总览：[frames/contact-sheet.jpg](frames/contact-sheet.jpg) · 分镜：[storyboard.md](storyboard.md)

## 这一集要的感觉，怎么落到画面上

| 要的感觉 | 画面上的做法 |
|---|---|
| 哲学启示感 | 星空的尺度、大量留白、慢。画面里永远只有一件事在发生 |
| 历史宿命感 | 古籍竖排、历书界栏、碑刻双线框、朱砂印、二十八宿星盘 |
| 人生的参数写在宇宙里 | 人是星点，乘法是星星熄灭，你的参数排成一页历书，最后盖上「写定」 |

## 色板

| 名字 | 色值 | 用在哪 | 大约占比 |
|---|---|---|---|

| 朱砂 | `#B3412E`（发光用 `#D0583F`） | **只给印章和 L** | ≤ 2% |

## 字体

- **中文：思源宋体**（Noto Serif SC），400 / 600 / 900。宋体是古籍感的来源，这一集不用黑体
- **公式、拉丁字母、数字：EB Garamond**，变量用斜体，数字用等高数字
- **字幕**：思源宋体 600，1080 宽画面里 44–48px，骨白，不描边，加一层柔和阴影，放在画面 70%–76% 高度
- 两套字体都是 OFL 协议，可以免费商用。剪映里没有思源宋体，就导入字体文件；实在不行用剪映自带的宋体类字体，别换成黑体

## 版式

- 竖屏 1080×1920
- **安全区**：关键文字放在 x 84–920、y 160–1500 之内。底部约 22% 是平台的标题和文案，右侧约 14% 是点赞、评论按钮
- **竖排只给"宿命句"**：开场那句、金唱片的问候、结尾 outro。数字和公式一律横排
- 左上角标「余数 —— EP 01」全片常驻，结尾换成居中的大标志

## 母题（全片反复出现）

1. **人 = 星点**。"你"是一颗带朱砂细圈的星，开场出现，中段（S10）再回来
2. **乘法 = 星熄灭**。公式每乘一项，画面上的星熄掉一片
3. **公式是碑文**。德雷克公式刻在双线框的碑上，L 从第一次出现就比别的项亮一点，给结尾埋伏笔
4. **你的参数是一页历书**。界栏、竖排、空着的填写线，最后一列"皆已写定"
5. **朱砂印只盖三次**：「一九六一」（公式诞生）、「写定」（你的参数）、「由你」（最后一项）。盖多了就不值钱了
6. **二十八宿星盘**：角亢氐房心尾箕……做成背景里的刻度环，透明度压到 30%–45%
7. **城市即星空**：每扇亮着的窗是一颗没连上线的星
8. **金唱片**：线稿致敬（脉冲星地图、外圈刻字 *To the makers of music — all worlds, all times*，这句是真的刻在唱片上的）

四字印按今天的阅读习惯，从左到右、从上到下排。古法是右列先读，但观众扫一眼会读反（「一九六一」会被读成「六一一九」）。

## 动态

- **镜头**：只用慢推、慢拉、慢摇，速度每秒 2%–4%；一个镜头至少停 4 秒
- **星点**：缓慢漂移，少量闪烁，周期 3–6 秒
- **文字**：逐字浮现，每字 60–80 毫秒；竖排从上往下，多列从右往左
- **乘法**：每乘一项，对应比例的星点在 0.6 秒内淡出
- **盖印**：落印时画面轻震两帧，印色从 60% 加深到 100%，配一声磬
- **转场**：交叉淡化或星轨拖尾。不闪白，不快切，不加光效
- **节奏**：全片只有 S06 的连乘是快的

## 声音

- 底：低频 drone + 稀疏钢琴，单音，尾巴留长
- 费米那段：一点无线电底噪（SETI 那种嘶嘶声）
- 金唱片那段：唱片沙沙声。普通话问候那句建议自己录，或请人录
- 盖印：一声磬或钟
- **版权**：金唱片原始音频里的音乐有版权，不要直接用；BGM 用平台曲库或免版税素材

## 如果要实拍

- 可以拍：夜里高处俯拍城市、星空延时、黑板粉笔特写、过年饭桌的空镜（不拍人脸）
- 处理：降饱和、偏冷、加颗粒；线稿用"滤色 / Screen"叠在实拍上
- 不要拍：婚礼、情侣、相亲现场

## 不要

- 粉色、爱心、婚礼素材、表情包
- 科幻大片式的 3D 星球和炫光
- 卡点快剪
- 朱砂红用在印章和 L 以外的地方
- 粗黑体大字幕

## 改样张

源文件是 [frames/src/frames.html](frames/src/frames.html)（HTML + CSS + Canvas，星点用固定种子生成，每次渲染结果一样）。改文字或位置就直接改这个文件，然后重渲：

```bash
cd frames/src
npm i playwright && npx playwright install chromium
node render.cjs            # 全部重渲
node render.cjs f03 f05    # 只渲指定几张
```

字体默认从 jsDelivr 加载；离线渲染的方法写在 `render.cjs` 开头的注释里。
